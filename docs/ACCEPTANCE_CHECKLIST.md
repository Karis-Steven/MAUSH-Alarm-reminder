# V1 手动验收清单

发布前在 Windows 10/11 实机执行。自动化测试已覆盖状态机、计时、配置、备份和界面命令；以下项目还需验证真实桌面、声音设备与系统会话行为。

- [ ] 分别选择真实 M4A、WAV、MP3，均能试听和停止试听。
- [ ] 工作结束时休息音与休息倒计时同时开始。
- [ ] 休息结束时继续工作音与工作倒计时同时开始。
- [ ] 点击 X 后窗口隐藏，托盘图标存在，计时继续。
- [ ] 托盘的显示、暂停/继续、停止、退出全部生效。
- [ ] 提醒音播放中点击停止，声音立即终止且不再切换阶段。
- [ ] 锁屏再解锁后显示“因系统暂停，等待继续”。
- [ ] 睡眠/休眠恢复后保持暂停，用户点击继续前不计时。
- [ ] 在无开发环境的 x64 Windows 设备上启动自包含发布包。
